# 小二 · 详细说明

README 只保留项目介绍，这里放实现细节、配置表和排障说明。

## 悬浮条

- 无边框、置顶、可拖动，单击展开/收起；收起态高 56，宽度随勾选的工具和账号图标自适应；展开态宽 440，高度贴着内容算。
- 靠边隐藏：收起态鼠标离开 0.5 秒后向上滑出屏幕，鼠标贴到顶部中央再滑回来；展开态、拖动中、浮层开着时不收起。托盘菜单可关闭。
- 应用图标：深色圆盘 + 蓝色渐变环 + 机器人头像，托盘/任务栏/Alt-Tab/exe 统一；`island/branding.py` 运行时绘制 16–256 多尺寸，`tools/make_icon.py` 用同一逻辑生成 `assets/xiaoer.ico`。
- 单实例：`Xiaoer-IslandBar-v1`（QLocalServer），重复双击只把已在跑的那条唤出来，避免同一条提醒弹两遍。

### 展开面板

- 顶部日期 / 周几 / 时间。
- 左侧本机音乐，右侧聊天账号列表；没放歌时只留播放器列表，面板缩到账号列高度（约 440×162）。
- 底部工具条：第一个固定是「工具箱」，后面只放**胶囊上勾选的前 3 个工具**，顺序与胶囊一致。宽度只有 440，全铺太多会把标签挤成半截字；其余工具在胶囊上直接点。
- 工具箱里每行都有和胶囊一致的图标、名称和说明；勾选/取消即时生效，写入 `config.json` 的 `capsule_tools`；支持全选、恢复默认。新增的应用快开、报错现场包、文员工具默认不勾选，避免胶囊被 9 个图标挤满。
- 胶囊上只显示勾选工具的图标；鼠标移到图标上会立即弹出对应名称，移开或点击后消失。
- 新面板首次点开前若已勾选，启动阶段会离屏预热一次，避免 `QTabWidget`/`QPlainTextEdit` 首开卡顿。
- 工具箱开着时胶囊不自动收起，点「完成」或 Esc 关闭后恢复。

### 浮层收起规则

`island/popup_guard.py` 统一管理速查卡、剪贴板、提醒弹窗/列表、看图窗、应用快开、报错现场包、文员工具：

- 鼠标只是移开、或前台应用没变，不收起；
- 只有在本程序窗口之外按下鼠标，或前台**真的换了进程**才收起；
- 新浮层出现后 1.2 秒安定期，避开 Windows 在岛和浮层之间来回倒焦点；
- 钉住的速查卡、要求点「完成」的工具箱不参与自动收起。

## 未读检测与来消息

三路信号叠加，只读屏幕像素与窗口标题，不读聊天内容：

1. **红点徽标**：任务栏按钮/托盘图标上的红色小块，连续两拍采到才确认。
2. **明暗闪动**：必须真的来回跨中线 3 次才算；单纯变亮（悬停、选中）不算。鼠标停在图标上时不采样本，避免高亮和 tooltip 阴影误判。检出后保留 4 秒。
3. **新通知窗**：只认本轮新出现、且连续存在 0.6 秒的小窗；常驻辅助窗、一闪而过的加载窗不算。保留 6 秒。

防误报/防延迟的几条约束：

- 托盘态不再采任务栏按钮坐标，采不到像素时旧红点立即作废。
- “正在用这个客户端”按**进程**判定，不要求前台句柄等于主窗口；微信/飞书弹出子窗口时也会立即清红点。
- 刚清完未读的 1.5 秒内，新冒出来的小窗不算新消息。
- 客户端从“无未读”变“有未读”时，对应图标提亮、外圈描白边，每 0.65 秒亮灭一次；岛缩在顶部会自己滑出来，未读没读掉前不自动收起。

## 小工具

### 剪贴板历史

- 只记文字，默认留 30 条，固定项不占名额；同一条重复复制只把时间顶到最新。
- 展开态左下「剪贴板」打开列表，点一条写回剪贴板，☆ 固定，「清空」只清未固定；右上「多选」可勾多条后「合并复制」，按列表顺序换行拼接。
- 写回只写纯文本（`CF_UNICODETEXT`），不会把网页/Word 的 HTML、RTF 一起带过去。
- 密码管理器带“禁止采集”标记的内容、以及程序自己写回剪贴板的那次会跳过。
- 存在 `%APPDATA%\Xiaoer\clipboard.json`。

### 区域截图

- 胶囊「截图」按钮或全局热键 `Ctrl+Alt+X`（可配置，留空则不注册）。
- 按下后岛和歌词条先让开，整屏冻结成位图，拖动框选，松手复制进剪贴板并存 PNG 到 `图片\小二截图`（可配置）。
- 多屏各一层取景，缩放比例不同也不串；Esc、右键、✕ 都能取消。
- 收尾强保证：存盘或提示失败也会关掉取景层；`_on_picked` 用 `try/finally`，每层再加 `QShortcut(Esc)` 兜底。

### 提醒

- 胶囊铃铛新建；列表键看已有提醒；展开态底部也有入口。
- 新建：一句内容 + 时间（默认 10 分钟后，`Ctrl+Enter` 保存）；可“截图作为提醒”，或在截图 toast 里点「加提醒」，图片复制进 `%APPDATA%\Xiaoer\reminders\`。
- 到点：岛自己滑出，铃铛变琥珀色 + 红点，岛下方弹内容泡（内容、时间、缩略图）。可选「5 分钟后」「完成」或 ✕ 关掉（关掉算看过，条目保留但不再挂红点）。
- 列表：未完成按时间升序，可完成/删除；带图条目点缩略图开**应用内看图窗**（滚轮缩放、拖动平移、适应 / 1:1、Esc 关闭）；已完成折叠，7 天后清理。
- 提醒只在本机，无声音、不弹系统通知；岛没运行时到点不补弹，条目会标「已过期」。同一时刻只弹一条。

### Bejson / Excel 快捷键

- 胶囊花括号图标或展开态「Bejson」，用默认浏览器打开 `https://www.bejson.com`。
- 胶囊表格图标或「Excel 键」打开速查卡：9 组 75 条，顶部搜索可按按键或功能过滤；右上「钉住」后点别处也留着，标题栏可拖动，Esc / ✕ 关闭。
- 数据在 `island/cheatsheet.py::EXCEL_SHORTCUTS`，加 Word 速查只改数据。

### 应用快开

- 胶囊四格图标打开；直接扫描当前用户和公共开始菜单的 `.lnk`，列出本机应用，不再让用户进安装目录找 exe。微信、企业微信、飞书、钉钉、QQ、Chrome、VS Code、DBeaver、Excel、Word 等常用项置顶，其余中文在前、英文在后。
- 单击应用直接启动；顶部搜索框按名称或快捷方式路径过滤，清空恢复全量。右上「刷新」强制重扫；「项目」切到项目目录列表。
- 列表只读快捷方式文件名，不解析快捷方式内容、不联网；启动 `.lnk` 用 `os.startfile`，启动系统工具用 `subprocess.Popen`。
- 项目目录仍在 `%APPDATA%\Xiaoer\projects.json`：每行一个项目，右侧「代码 / 目录 / 终端」分别开 VS Code、资源管理器、Windows Terminal（没有则 PowerShell）；「+ 添加」选文件夹，「配置」用默认程序打开 JSON。

### 报错现场包

- 胶囊警告图标打开；自动抓当前时间、主机名、前台窗口标题、前台进程名和剪贴板文本（最多 6000 字）。
- 预览是 Markdown，剪贴板内容用 `~~~~text` 围栏，避免内容里的反引号破坏格式。
- 「复制（含剪贴板）」把整段 Markdown 写回剪贴板；「仅窗口信息」不带你剪贴的内容，适合发群前先脱敏。
- 写回时会通知剪贴板监听器跳过，避免这条现场包又被记成一条历史。

### 文员工具

- 胶囊文档图标打开，五个页签全部本地计算，不联网：
  1. **金额**：人民币小写转大写，支持逗号、`￥/¥`、结尾「元」，最多两位小数，负数；最大到 9999 万亿元。
  2. **日期**：两日期相差（自然日 / 工作日），或从起始日加/减 N 个工作日；工作日只跳周六日，**不含法定节假日和调休**。
  3. **重命名**：只改当前文件夹内的文件，生成 `前缀_001.ext`；先预览，执行前二次确认，目标重名则整体中止；不可撤销。
  4. **清单**：导出当前文件夹（可选含子文件夹）的 CSV，字段为相对路径、名称、类型、扩展名、大小(KB)、修改时间；`utf-8-sig`，Excel 直接打开，最多 5000 条。
  5. **文本**：去空行、去首尾空格、去重复行、加行号，适合整理 PDF/Excel/网页粘贴出来的文本。
- 剪贴板列表新增「多选」：进入后逐条勾选，底部「合并复制」按列表顺序用换行拼接并写回纯文本；写回只放 `CF_UNICODETEXT`，不带网页/Word 的 HTML、RTF 格式。

## 本机音乐与歌词

- 优先 Windows 系统媒体会话（SMTC）拿封面、歌名、控制；客户端不上报时（网易云桌面版常见）改读主窗口标题，再去网易云接口取封面。
- 播放/暂停判定顺序：
  1. CoreAudio 会话状态：Inactive 持续 1.2 秒以上才判暂停（切歌、缓冲的瞬时归零不算）。
  2. 有音频流且未静音时看峰值：播放 > 0，暂停约 0.5 秒掉到 0。
  3. 系统整体静音时看播放器窗口里的进度线是否在动：1.6 秒不动判暂停，有位移判播放。
- 点播放/暂停先本地翻转图标并记住用户意图，1.2 秒内以点击结果为准，随后由真实证据校正；上一首/下一首同理。
- 岛下方歌词条与岛同宽，按进度自动走句，暂停停在当前句；岛靠边隐藏时歌词条贴住屏幕上沿。
- 进度优先读播放器窗口底部进度线的像素位置（暂停也能读到停在哪），读不到才退回 `core/progress.py` 按时间推算。
- 完全没有音乐时列出本机 QQ音乐 / 网易云音乐 / 酷狗音乐，点一下启动或切前台；一个都没装显示“无音乐播放器”。

## 唤起聊天窗口

按客户端组合三种策略（`core/im.py::IMClient.activation_order`），每档点完都轮询验证窗口真的可用（UIA 的 Invoke 一律返回成功，不能拿调用成功当窗口起来了）：

1. `launch`：像双击快捷方式再启动一次客户端，单实例客户端会把请求转给已运行实例，自己显示主窗口。企微/飞书/QQ/钉钉走这条，实测 0.4–0.5 秒。微信关掉这条——再启动 `Weixin.exe` 会真的多开一个实例，闪一下又退出。
2. `shell`：UIA 点任务栏按钮或托盘图标。顺序是托盘直露图标 → 任务栏按钮 → 隐藏图标浮层（最后才用，因为会闪一下右下角面板，点完立即收起）。
3. `force`：外部强制显示，兜底。先把离屏窗口 `SetWindowPlacement` 搬回可见区，显示后做一次一像素尺寸抖动逼重绘。企微主窗口收托盘时仍在屏幕内，`force` 最快，所以排第一。

Windows 前台锁拒绝 `SetForegroundWindow` 时，敲一次 Alt 解锁重试并校验 `GetForegroundWindow`；客户端重建主窗口时按“同进程同客户端”重新解析句柄。不用 `AttachThreadInput`（解绑失败会让目标窗口看得见却点不动）。点击账号后岛立即收起，避免挡住刚唤起的窗口。

## 头像占位（桌面小伙伴暂停）

- 胶囊右侧头像现在是暖棕色木鱼图标（`assets/wooden_fish.png`），没有外圈、没有绿色，只作视觉占位。
- 点击头像时整只木鱼会左右抖动两下，并在下方弹一个约 0.4 秒的「功德 +1」小提示；提示只负责显示，不计数、不写文件，连点只会重置同一条提示。
- 不接收照片、不生成小人、不上传、不联网；旧的 `CompanionWindow` 和照片处理代码保留在 `island/companion_ui.py`，但没有装配到运行流程。
- 后续要接用户自有模型时，从 `main.py` 恢复装配，并把头像按钮替换成生成结果的入口。

## 托盘、性能与日志

- 托盘菜单：展开/收起、开机自启、靠边自动隐藏、显示歌词、新建提醒、提醒列表、退出。
- 窗口枚举 2 秒一次、红点采样 0.3 秒一次，都在后台线程；界面只重画。
- 枚举与采样分开计时、分开调速：枚举最多放宽到 4 秒，采样最多 0.6 秒；连续 10 个快轮次逐步收回基础节拍，不会一次卡顿永久停在 1.5 秒/8 秒。
- 音乐/歌词/靠边轮询也按耗时自适应；明显变慢写进 `%APPDATA%\Xiaoer\perf.log`。

## 新增一个客户端

在 `core/im.py` 写一个 `IMClient` 子类并注册一行，枚举、去重、唤起和界面都不用改：

```python
class DingTalkClient(IMClient):
    key, name = "dingtalk", "钉钉"
    exes = ("dingtalk.exe",)
    class_exact = ("StandardFrame_DingTalk",)
    shell_names = ("钉钉", "DingTalk")               # 任务栏/托盘显示名前缀
    activation_order = ("launch", "shell", "force")  # 再启动 → 系统入口 → 强制显示
    supports_launch = True                            # 单实例客户端才开
```

## 已知限制

- 红点是“按客户端”粒度：同客户端多开时任务栏只合并一个按钮，无法区分具体账号。
- 网易云桌面版 SMTC 不带进度时，歌词依赖读窗口底部进度线；播放器最小化到托盘、被完全遮挡、或拖完进度条立刻最小化时，会退回按时间推算，可能差一段。要彻底准确需给网易云装 BetterNCM + InfLink-rs 上报时间轴。
