# 小二（Xiaoer）

Windows 桌面悬浮条，参照灵动岛：收起态是贴着屏幕上沿的一条胶囊，展开态放本机音乐、聊天窗口直达和常用小工具。

纯本地运行，只读窗口标题和屏幕像素判断未读，不读聊天内容；除歌词/封面接口外不联网。

## 功能亮点

- **胶囊态**：时间、智能体头像、微信 / 企微 / 飞书 / QQ / 钉钉图标。有未读时图标闪烁并亮红点，点一下直达对应窗口；鼠标离开 0.5 秒自动滑出屏幕，贴顶再唤出。
- **展开态**：日期、本机音乐（封面 / 歌名 / 播放控制 / 歌词条）、多开账号列表、工具入口，高度随内容自适应。
- **未读检测**：托盘/任务栏红点 + 图标明暗闪动 + 客户端新通知窗三路信号；悬停不误报，读完立即清，托盘态也能追到。
- **小工具**：剪贴板历史（支持多选合并）、区域截图（`Ctrl+Alt+X`）、提醒（可配截图，应用内看大图）、Bejson、Excel 快捷键速查（75 条，可钉住）、应用快开、报错现场包、文员工具。工具箱里勾选胶囊上显示哪些；工具箱每行带图标，胶囊图标悬停显示名称。
- **应用快开**：直接读开始菜单列出本机应用，常用应用置顶；点一下或搜索后回车即启动，不用再进安装目录找 exe。右上「项目」进入原项目目录列表。
- **智能体头像**：胶囊右侧一只暖棕色木鱼占位，无外圈；点一下整只木鱼左右抖两下并弹「功德 +1」小提示。桌面小伙伴的照片生成功能暂停，后续接用户自有模型。
- **单实例、单文件**：重复启动只唤出已在跑的那条；可打包成一个 exe，目标机无需 Python。

## 快速开始

程序目录里的 `run.bat` 已指向本机 Python 环境，直接双击即可；`build.bat` 打包出 `dist\小二.exe`。

## 数据目录

`%APPDATA%\Xiaoer\`，在本机就是 `C:\Users\<用户名>\AppData\Roaming\Xiaoer\`：

- `config.json`：配置
- `reminders.json`、`reminders\`：提醒与截图附件
- `clipboard.json`：剪贴板历史
- `projects.json`：项目目录列表（应用快开右上角「项目」进入）
- `perf.log`、`error.log`：性能与崩溃日志

`%APPDATA%` 是**当前登录用户**的漫游数据目录，不是全机公共目录；换 Windows 账户或换机器就是另一份。资源管理器地址栏输入 `%APPDATA%` 可直接打开。

## 项目结构

```text
main.py            入口：应用、托盘、自启、单实例
island/            悬浮条、后台扫描、工具浮层与提醒界面
core/              配置、IM 枚举与唤起、未读检测、媒体与歌词、本地存储
tools/             图标生成等辅助脚本
```
